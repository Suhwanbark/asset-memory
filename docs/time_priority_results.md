# Time-aware 정보 우선순위 — feasibility POC 결과

2026-09-28. 실행 종료. Memory·검색·요약 없이, 두 정보를 직접 비교하는 소형 모델 실험임.

## 결론부터

**근거가 있는 A/B 평가를 구성하고 실행하는 것은 가능했으나, 지금 결과만으로 ‘LLM은 시간별 정보가치를 이해하지 못한다’는 주장이 성립하지는 않음.**

- 공식 출처의 적용 기간·계약 조건을 이용하면 정답을 연구자의 투자 직관에만 의존하지 않고 설명할 수 있음.
- 날짜가 바뀌어도 같은 선택을 유지하는 실패가 관찰됨. 그러나 선택지 위치 편향도 매우 커서 시간 특이적인 실패와 분리되지 않음.
- 마지막 형식에서는 단순 독해 통제를 두 모델 모두 통과했지만, 금융 판단의 전반적 독해·객관식 선택 편향까지 배제한 것은 아님.
- 실제 뉴스의 경제적 정보가치나 예측력보다는 **주어진 업무에 대한 시간 조건부 적용 가능성·중요도**를 측정한 하한선 POC임. 회의에서 논의한 넓은 information utility와 동일시하지 않음.

| 항목 | 설정 |
| --- | --- |
| 모델 | Qwen3-1.7B, SmolLM2-1.7B-Instruct |
| 실제 parameter 수 | 1,720,574,976 / 1,711,376,384 |
| 입력 | 현재 평가 날짜 + 명시한 업무 + 실제 출처 기반 두 evidence card |

후속 형식에서도 evidence·질문·평가 날짜·정답을 수정하지 않음. 동일한 50문항 전체를 실행했으며 오답만 재생성하지 않음. 단, v2/v3는 v1의 문제를 본 뒤 만든 개발 진단이므로 독립 holdout 결과가 아님.

각 문항의 A/B, B/A 두 순서를 모두 집계한 점수임. 따라서 전체 분모 100은 **50문항의 두 번 측정**이며 독립 100사례가 아님.

## 3. 실제 사례: 날짜만 바꿔도 우선할 정보가 바뀌어야 함

### BTFP와 할인창구

- 정보 A: 할인창구에서 최대 90일의 신규 대출을 받을 수 있음.
- 정보 B: BTFP에서는 최대 1년까지 가능하지만, 2024-03-11에 신규 대출이 종료됨.
- 동일 질문: 적격 담보를 가진 기관이 **오늘 신규로 가장 긴 초기 만기의 자금을 조달**하려면 어느 정보를 우선해야 하는가? 후속 연장·규정 변경 없음, 재대출은 계산하지 않는다고 명시함.

| 평가 날짜 | 정답 | v3 Qwen / Smol, A/B 순서 |
| --- | --- | --- |
| 2024-03-01 | BTFP: 아직 가능하고 만기가 더 김 | BTFP / BTFP |
| 2024-03-20 | 할인창구: BTFP 신규 조달은 이미 종료 | BTFP / BTFP |

이 표만 보면 만기 숫자만 보고 종료일을 무시한 것처럼 보임. **그러나 순서를 바꾸면 두 모델 모두 두 날짜에서 할인창구를 선택함.** 이 사례에서는 어느 제도인지보다 두 번째 선택지(B)를 고르는 패턴이 드러남. 날짜에 적절히 반응하지 못했다는 관찰은 가능하지만, 원인을 특정 시간 인식 결함 하나로 단정할 수 없음.

출처: [BTFP 조건](https://www.federalreserve.gov/newsevents/pressreleases/monetary20230312a.htm), [종료 공지](https://www.federalreserve.gov/newsevents/pressreleases/monetary20240124a.htm), [할인창구 조건](https://www.federalreserve.gov/newsevents/pressreleases/monetary20200315b.htm). 실제 제도 발표에 근거한 연구자 작성 상황이며, 당시 시장의 모든 후속 정보까지 재현한 것이 아님.

### 설명을 요청했을 때 나타난 예 (v2, 별도 형식)

Qwen은 같은 BTFP의 2024-03-20 문항에서 종료일인 3월 11일이 평가 날짜 ‘이후’라고 설명하고 BTFP를 선택함. 그러나 선택지를 뒤집은 응답에서는 종료됐음을 맞게 해석함. 이는 실제 날짜 비교 오류가 포함된 예지만, 순서에 불변한 오류는 아님. 또 다른 사례에서는 과거 주식분할보다 최근 배당이 주식 수 환산에 더 관련 있다고 설명함. 설명은 공개 출력이며 모델 내부 사고를 직접 관찰한 증거로 취급하지 않음.

## 4. 인터페이스 진단 이력

| 형식 | Qwen 전체 / 독해 통제 | Smol 전체 / 독해 통제 |
| --- | --- | --- |
| v1: A/B를 먼저, 뒤에 짧은 설명 | 50% / 4/8 정답 | 50% / 4/8 정답 |
| v2: 짧은 설명 뒤 최종 Answer 요청 | 66% / 6/8 정답 | 56% / 4/8 정답 |
| v3: 최소 지시문, 선택지 글자만 요청 | 65% / 8/8 정답 | 63% / 8/8 정답 |

v1에서 Qwen은 98/100, Smol은 100/100회 A를 선택함. v3에서는 Qwen 85/100, Smol 81/100회 B를 선택함. 프롬프트 형식에 따른 위치 선호 변화가 매우 커서 단일 점수를 능력의 안정적인 추정치로 보기 어려움.

v2의 일부 Qwen 출력은 `Answer:`를 새 줄이 아닌 설명 끝에 붙였음. 공백/줄바꿈만 허용한 정규식으로 8개를 인식했고, strict-newline 점수 62%에서 66%로 집계가 바뀜. 원본 응답과 strict label을 그대로 보존함. 의미를 추측하는 LLM judge나 정답에 맞춘 재채점은 하지 않음. 전 버전 hash와 응답 600개가 남아 있음.

## 5. 데이터와 판정의 남은 제약

1. **진짜 시간 전환 쌍이 3개뿐임.** 전체 50문항이라는 수치만으로 표본이 충분하다고 할 수 없음.
2. **형식·위치 편향이 큼.** 날짜를 무시한 오류와 일반 MCQA 선택 오류가 섞여 있음. 날짜만 비교하는 독립 통제도 추가할 필요가 있음.
3. **질문이 목적 지향적으로 좁음.** 신규 대출·상환 일정·주식 수 환산에는 명확한 정답을 만들 수 있지만, ‘어떤 뉴스가 지금 예측에 더 유용한가’ 전체를 다루지 못함.
4. **source-grounded지만 사람이 독립 검증한 gold는 아님.** 개별 문제의 유일성과 업무상 의미를 확인하는 검토가 필요함. 인간의 선호를 곧 정보가치의 정답으로 쓰자는 뜻은 아님.
5. **발표 자료와 가상의 업무 조건을 결합함.** 원문은 실제지만, 질문과 카드·보유 조건은 연구자가 구성함. 자연 발생 고객 로그, 실제 Polymarket 실행, 당시 시장 snapshot 전체가 아님.
6. **PPPLF clock pair 근거 문구의 경미한 과특정:** gold 설명에 2025 만기를 예시로 적었지만 실제 clock 질문은 ‘90일보다 긴 적격 담보’만 가정함. 비교 결론(90일보다 긴 신규 만기 / 종료 후 이용 불가)은 유지되지만 2025를 입력 사실로 주장하면 안 됨. 동결 gold는 수정하지 않고 이 주석을 남김.

## 6. 다음 판단

현 시점의 권장 결론은 **‘실행 가능한 평가 틀은 만들었고, 시간에 맞춘 선택이 안정적이지 않은 사례도 있으나, 연구의 핵심 현상을 깨끗하게 입증한 단계는 아님’**임.

다음에는 같은 50개를 원하는 점수가 될 때까지 수정하기보다, 별도 개발/검증 분할에서 (1) 실제 독립 사건의 clock-only 쌍 확대, (2) 일반 날짜·금융 독해 통제와 label 위치 편향 제거, (3) 단어 관련성만으로 풀리지 않는 정보가치 정의를 검토하는 것이 우선임. 시장 가격 변화나 사후 YES/NO 결과를 정보 중요도의 인과적 gold로 곧바로 사용하는 것은 피해야 함. 아직 Memory 실험을 시작할 단계라는 결론은 내리지 않음.
