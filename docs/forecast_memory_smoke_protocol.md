# 실제 실적발표 Memory smoke — 사전 고정 프로토콜

2026-09-28. 옛 recall/replicate 삭제 후 새 실험. 이전 수치와 직접 비교하지 않음.

## 질문과 고정 사례

과거 전망의 시점·대상 기간·확실성이 Memory 형성/검색 중 변형되고 후속 분석 오류로 이어지는가?
먼저 NVIDIA(2022-05-25 → 2022-08-24), AMD(2022-08-02 → 2022-11-01), Intel(2024-04-25 → 2024-08-01) 3사례.
전망 미달 2개와 매출 전망 범위 충족 1개. 모델 출력 확인 전 사례 고정. 모집단 오류율 추정용 무작위 표본 아님.
중간 공시가 없었다고 가정하지 않음. 선택한 두 연구 업무 사이의 비교이며, 최신 자료의 과거 전망 재진술을 제거하지 않음.

## 실행

- Source는 실제 과거 공시 파일을 읽고 실적/사업/전망/관찰사항 메모 작성. Persona·미래 질문·정답 미제공.
- 전체 과거 공시+요청+실제 공개 분석 메모를 한 세션으로 Mem0.add(infer=True)에 입력.
- Tool observation은 출처·날짜와 함께 assistant 역할로 정규화. 금융/예측 보존용 custom extraction prompt 없음.
- 같은 현재 공시+중립적 업데이트 질문을 독립 stateless 세션에 제공.
- No Memory / Full History / Mem0 Top-10 / Mem0 전체 저장소(검색 손실 분리 진단).
- 모델 GPT-5.6-luna, low. 공식 mem0ai 2.2.1 SDK 기본 추출·저장·검색 유지, LLM transport만 Codex CLI, embedding은 CPU MiniLM.
- 기본 Qdrant 경로 사용. optional BM25 가용성도 실행 로그에서 확인. 제한/변경사항은 결과에 명시.
- API-key 없음: 사용자 과거 노출 키 사용하지 않음. 기존 인증으로 Codex 실행; prompt·이벤트·공개 최종 응답 저장.

## 판정 (모델 결과 보기 전)

1. 전망을 확인된 실적처럼 진술했는가? 대상 기간을 바꾸거나 전망 대비 차이를 QoQ 변화로 잘못 진술했는가?
2. 과거 전망의 값·대상 기간·후속 결과를 모두 맞게 연결했는가? 정확한 비교 coverage 별도.
3. 정당한 정보 부족/생략은 사실 오류로 채점하지 않음. No Memory가 현재 공시에서 비교 가능하면 성공으로 인정.
4. 원문 → Source 분석 → 전체 store → retrieved → 후속 답변 각각 근거 구절 확인.
5. 저장 누락과 거짓 사실화는 별도. Memory 조건 오류만으로 인과 주장 금지.
6. 기대 실패가 없으면 null 결과. 정답/자료/질문을 성능에 맞춰 사후 수정하지 않음.

첫 3개는 빠른 존재 확인이며 long-context/장기 누적/general benchmark 검증이 아님.
